# 掌柜助手

个人卖家本地电商运营工具，双平台（拼多多 + 闲鱼），核心理念：简单化操作。

## 环境要求

- Node.js 22+

## 快速开始

```bash
npm install
npm run build
npm run lint
npm test
```

## 目录结构

```
apps/server   后端（Fastify + TypeScript + SQLite）
apps/web      前端（React + Vite + Tailwind）
packages/shared 前后端共享 schema / 类型 / 常量
tests         测试
```
